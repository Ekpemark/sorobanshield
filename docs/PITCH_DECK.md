# SorobanShield pitch deck copy

## 1. SorobanShield
Open, local-first audit preparation for Soroban Rust contracts.

## 2. The problem
Soroban developers need fast security feedback that reflects explicit authorization, storage lifecycles, Rust arithmetic, and host-mediated contract calls.

## 3. The solution
SorobanShield turns local source scans into evidence-based findings with a rule, line, explanation, and remediation.

## 4. Why Soroban
The product is purpose-built for Soroban’s Rust SDK and security model rather than EVM assumptions.

## 5. What exists today
A public browser MVP with four deterministic checks and Markdown report export. It is audit preparation, not an audit.

## 6. Architecture
Local source input → parser and versioned rule pack → explainable findings → Markdown/JSON/SARIF output. Optional hash-only review registry; source never goes on-chain.

## 7. Security and privacy
Local-first processing, explicit limitations, versioned rules, fixture tests, and no on-chain source storage.

## 8. 30-day scope
Ten documented rules, twenty safe/vulnerable fixtures, testnet walkthrough, public beta, and five feedback sessions.

## 9. Budget
$3,500 engineering; $500 hosting and CI; $1,000 community testing, documentation, and demo. Total request: $5,000 equivalent in XLM.

## 10. Ask
An Instaward-aligned 30-day execution sprint and feedback from the local Stellar Ambassador Chapter.
