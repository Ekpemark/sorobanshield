# SorobanShield delivery roadmap

## 30-day Instaward sprint

| Week | Deliverable | Evidence |
|---|---|---|
| 1 | Rule catalogue, scanner test harness, and 10-rule implementation plan | Public issues, tests, release notes |
| 2 | Twenty safe/vulnerable fixtures and deterministic rule tests | Fixture directory and passing CI |
| 3 | Local CLI/report formats and Soroban testnet walkthrough | Versioned CLI output and demo recording |
| 4 | Public beta, five structured feedback sessions, and improvements | Tagged release and anonymized feedback summary |

## Three-month path

| Month | Outcome | Measure |
|---|---|---|
| 1 | Reliable open beta | 10+ rules, 20+ fixtures, tests, documented limitations |
| 2 | Developer workflow | Local CLI, JSON/SARIF reports, GitHub Action prototype, testnet walkthrough |
| 3 | Validation and iteration | Community feedback, precision fixes, public knowledge base, release report |
